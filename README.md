**Software for the small businesses that hold a town together.**

Fledge builds tools for one- to five-person service businesses, the people who
do the work themselves. Founded in 2026 with
Christian Arroyo and incubated by BuyIt
Ventures.

## How I work

- **Say what it does, and not more.** A README should tell you what is built,
  what is being built, and what is only an idea, and keep the three apart.
- **Own your stack where it matters.** Your money data, your models, your
  network. If I can run it myself without much pain, I usually do.
- **Small, verified changes.** Most of my code ships as short pull requests
  with tests, and a lot of it is written alongside AI agents I've set up to
  work that way.
